# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

People who save useful links from apps and the web and want one account-backed place to organize and revisit them.

## Product Purpose

UniMark collects links shared from other apps or the web into a personal library. Users can revisit saved links and organize them with custom titles and folders.

## Positioning

UniMark brings links from multiple apps and web sources into one library, using the device share flow as the capture path.

## Operating Context

Users encounter a link in another app or in a browser, share it to UniMark, then later browse their library, search saved links, or filter by folder. The app supports Android and iOS.

## Capabilities and Constraints

- Sign in or create an account with email and password or Google.
- Receive shared links, save them to an account, and preserve the original URL separately from a custom title.
- View, search, and delete bookmarks; create, rename, delete, and filter by folders; assign a bookmark to folders.
- The mobile client is built with React Native. The backend and database are separate services.
- The current request is a full visual redesign; existing sign-in, sharing, bookmark, search, and folder behavior must remain intact.

## Brand Commitments

- Product name: UniMark.
- No logo, color palette, or visual style is a required commitment; the user asked for a new interface and new colors.

## Evidence on Hand

- The working mobile app and backend implement the capabilities listed above.
- No user testimonials, customer metrics, or approved promotional claims have been provided.

## Product Principles

- Capture should begin from the app where the user found the link.
- Preserve a link's original destination while allowing users to give it a useful title.
- Let users organize and retrieve links with straightforward library tools.
- Keep the library associated with the user's account across sessions.
